## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/Java-basics.git
```

Replace `YOUR_USERNAME` with your GitHub username.

### 2. Navigate to the Project Folder

```bash
cd Java-basics
```

### 3. Compile a Program

For example, if your file is named `j11.java` and contains a class named `Main`:

```bash
javac j11.java
```

### 4. Run the Program

```bash
java Main
```

**Important:** These examples use the class name `Main`. Since Java requires the public class name to match the filename, these examples can use filenames such as `j11.java` because `Main` is not declared as a public class.

Each program should be compiled and run separately because all examples use the class name `Main`.
