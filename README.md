## 🚀 How to Run

Clone this repository:

```bash
git clone https://github.com/YOUR_USERNAME/Java-basics.git
```

Navigate to the project folder:

```bash
cd Java-basics
```

Compile a Java program:

```bash
javac j65.java
```

Run the program:

```bash
java Main
```

**Note:** Each Java file uses a class named `Main`. Compile and run one file at a time.

For JDBC programs, include the MySQL Connector/J JAR file in your classpath and configure your MySQL credentials.
